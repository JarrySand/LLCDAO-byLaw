> ✅ **本チェックで抽出した不整合は全て修正済み（3周レビュー完了）。修正内容は [規程類修正結果まとめ_定款ver3.3.md](規程類修正結果まとめ_定款ver3.3.md) を参照。**

## 0. 根本原因（3つの構造変更）

ver2.0 → ver3.3 で規程類に波及する構造変更は次の3点。これがほぼ全規程に連鎖している。

| 変更 | ver2.0 | ver3.3 |
|---|---|---|
| **A. 社員同意・否認決議の廃止** | 第18条（社員の同意・否認決議）あり。「DAO投票→社員同意」二段階モデル | **条ごと削除**。モデル自体が消滅 |
| **B. 拒否権の移動** | 第19条（拒否権） | **第18条**へ移動。かつ「DAO総会規程が定められている場合のみ有効」の条件付き |
| **C. 業務執行社員会の新設＋全体の条ズレ** | 機関なし／計算は第21-24条 | **第20-23条で正式機関化**／計算は第24-27条／規程管理規程は第30条 |

> ※特にAは単なる番号置換ではなく、「DAO投票→社員同意」モデルを「DAO総会＋業務執行社員会」モデルへ置き換えた**設計思想の転換**であり、関連条文は文面の作り直しが必要。

## 4. 推奨アクション

1. **番号置換のみで済む箇所**（②③④）を先に修正
   - 拒否権：第19条 → 第18条
   - 計算書類：第22条 → 第25条
   - 規程管理規程フォールバック表：第12条第6項→第8項、第14条第2項行を削除
2. **制度系**（①）はDAO総会規程・運営規程の該当条を書き直し
   - DAO総会規程 第5条・第11条・第4章：社員同意手続きの削除／拒否権参照への一本化
   - 運営規程 第2条：否認決議の削除、拒否権参照を第18条へ
   - 用語集：否認決議・社員同意の項を見直し、規程管理規程・業務執行社員会の項を追加
   - 運用ガイド：「DAO投票→社員同意」モデルの記述を「DAO総会＋業務執行社員会」へ更新
3. **方針判断が必要な箇所**（⑤）はDAOで建付けを決定後に反映
   - 業務執行社員会：必置（定款第20-23条）と運営規程第4条（任意設置）の関係整理
   - 代表社員の選定方法：互選の扱い
