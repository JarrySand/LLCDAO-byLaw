## 4. 確認推奨ポイント（法務観点）

修正は条番号・廃止制度の整合を主目的としており、以下は方針確認の余地がある。

1. **第5条/第11条の社員同意手続き**：ver3.3は旧第18条の定型手続（○○日以内の同意・否認決議）を廃止し、第15条第10号の「事前協議・決定」に一本化。会社法上の総社員同意の取得フロー（誰が・いつ・どの方法で）を規程側でどこまで具体化するか。
2. **業務執行社員会（運営規程第4条）**：規程あり時は定款第5章不適用のため、必要な権限・招集・決議要件を運営規程側で過不足なく定義できているか（現行第4条は概括的）。
3. **トレジャリー管理規程**：定款第12条第3項が参照する正式規程の整備（現状WIP）。
